Line icons for the card grid (`boxes.html`, item field `icon`) and the search link of the header (`search.svg`), taken from Lucide (https://lucide.dev, ISC license).
Each file is inlined as is: `stroke="currentColor"`, no size (set by the including element); `search.svg` takes
the include parameter `size` (width and height in px).

`flag-de.svg` and `flag-gb.svg` are the flags of the language switch in the header (sized in the file).
