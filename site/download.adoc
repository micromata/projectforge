ProjectForge is open source and free – with all features and no limits on users. Pick the way you want to run it.

== Get ProjectForge

[cols="1,2,3",options=header]
|===
|Type |Link |Description

|Docker
|https://hub.docker.com/r/micromata/projectforge[Docker Hub,window=_blank]
|The easiest way: image for a single container or a Docker Compose stack with PostgreSQL. Recommended for production.

|Executable JAR
|https://github.com/micromata/projectforge/releases[GitHub releases,window=_blank] (mirror: https://sourceforge.net/projects/pforge/files/ProjectForge/[SourceForge,window=_blank])
|Runs on Linux, macOS and Windows with Java 17 or newer – ideal for trying ProjectForge on your own machine.

|Sources
|https://github.com/micromata/projectforge[GitHub,window=_blank]
|Everything you need to build, change and extend ProjectForge yourself.
|===

== Updates

Updating is easy: stop ProjectForge, start the new version. Database schema and data are migrated automatically on the first start.
Back up your database before, and check the link:/docs/migration/[Migration guide] for the few changes that need your attention.

== Translations

ProjectForge is available in English and German, and fully internationalized. To add another language, translate the
https://github.com/micromata/projectforge/blob/master/projectforge-business/src/main/resources/I18nResources.properties[English translation file,window=_blank]
(format `key=Translation`, missing keys fall back to English) and contribute it via a pull request or a
https://github.com/micromata/projectforge/issues[GitHub issue,window=_blank]. We're happy to include it in the next release.
